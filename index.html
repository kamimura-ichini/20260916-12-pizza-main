AIを使う前に、いまの仕事を分解する。

仕事を3つに分ける

この3つを書き出せば、AIに渡す設計図になります。

PREP / 事前準備
何を参照するか
参照すべき正しい情報を集める。
  • 問い合わせ対応 … FAQ・回答方針
  • 打ち合わせ … 案件フォルダ
  • 週次の数字 … 集計用シート
  • 手順の更新 … 現行マニュアル
  • 比較検討 … 過去資料＋公開情報
TRIGGER / きっかけ
いつ始まるか
何が起きたら仕事が始まるか。
  • 問い合わせ対応 … メールが来る
  • 打ち合わせ … 会議が終わる
  • 週次の数字 … 月曜の朝
  • 手順の更新 … やり方が変わる
  • 比較検討 … 「調べて」と頼まれる
OUTPUT / 出力
何ができあがるか
成果物ができる。
  • 問い合わせ対応 … 返信下書き
  • 打ち合わせ … 要約と宿題
  • 週次の数字 … ダッシュボード
  • 手順の更新 … 改訂版ドキュメント
  • 比較検討 … 比較表

AIで実装するまでの4つの手順

studioとGASの操作方法

STEP 01
説明する
設計図の3点（参照先・きっかけ・出力）を日本語で書いて、Gemini（AI）に渡す。
STEP 02
生成させる
フローの設定内容やコードは、AIに作ってもらう。
STEP 03
確認させる
設定やコードをAIに確認させる（「なぜその設定か説明して」など）。テスト実行で、想定どおりの出力か確かめる。
STEP 04
動かす
オンにする、または保存して定期実行にする。ここまでで完成。
TIP
STEP 03の結果が期待どおりでなくても、やることは同じです。
いまの状況を説明し（画面のスクショを共有）、生成させて確認する。

GWS Studio：Geminiに説明して、フローを作る

コードは書きません。studio.workspace.google.com を開き、下の入力欄に日本語で書くとフローができます。

赤枠：「Gemini にタスクを説明」に書いて、右の「作成」を押す
STEP 01
Studioを開く
おすすめのテンプレート一覧もここで見られます。
STEP 02
AIに対して説明する
「何が起きたら、何をしてほしいか」を1文で。例：未読メールを朝に要約してChatへ。
STEP 03
フローが自動作成される
「作成」を押すと、開始条件とステップが自動で出てきます。

実装の途中で出る確認

実装中に権限の確認や注意が表示されても、社内で自分の作業なら想定どおりのことが多いです。落ち着いて中身を見て進めてください。

Workspace Studio
  • オンにする前に「テスト実行」が出る → 先に試してからオンにしてOK
  • 「このフローを実行しますか」など確認が出る → 内容を見て問題なければ進めてOK
  • 権限が足りない、と出る → 自分のメール／ドライブなら、許可して続けてOKなことが多い
GAS
  • 初回に Google の許可画面（「アクセスを許可」）が出る → 自分のスクリプトなら、本人が許可してOK
  • 権限の一覧が長く見える → シートやフォームを読む／書くために必要な範囲
  • 実行ログにエラーが出る → エラー内容（画面のスクショ）をgeminiに共有して、再度テストする。

やってよいこと / NGなもの

迷ったら入力しない、が原則です。判断に困る場合は佐藤さんや開発チームへ相談してください。

OK やってよい
  • 公開されている情報、自分で書いた文章
  • 調べもの、たたき台づくり、翻訳、要約、言い換え
  • 使い方が分からないツールの操作方法を聞く
NGなもの
  • 自治体・取引先から受け取った未公開資料、NDAの対象文書
  • 首長・政治家・秘書の、非公開の連絡先や住所を含むリスト
  • 公表前の調査データ、未公表の選挙関連データなど
GOVERNANCE
AIに読み込ませてよいものや、活用する際の確認は AI利用チェックリスト で行いましょう。

詳細 S1 / S2

S1 Studio
メールの自動タグ付け（ラベル自動分類）

Google Workspace Studio

受信したメールの内容や送信者をAIが解析し、重要度や案件別・カテゴリ別に自動でラベル（タグ）を付与します。手動での仕分け作業が不要になり、フォルダ整理の手間を削減できます。

PREP 事前準備（何を参照するか）
  • 使用するラベル一覧（例：問い合わせ／社内／緊急）
  • 分類ルール（含めるキーワード／除外条件）
  • 対象インボックス（自分のみ／共有トレイ）
TRIGGER きっかけ（いつ始まるか）
メール受信時（または過去メール一括処理の実行時）
OUTPUT 出力（何ができあがるか）
対象メールへの自動ラベル付与
S2 Studio
お問い合わせ内容の傾向分析と定期レポート作成

Google Workspace Studio

日々届く問い合わせメールを集約・解析し、「どのような質問が多いか」「顧客の課題は何か」などのトレンドを要約して定期報告します。顧客の声を素早く把握し、サービス改善やFAQ作成に活かせます。

PREP 事前準備（何を参照するか）
  • 対象メールの判定条件（件名／ラベル）
  • 集計対象期間（過去1週間／過去1ヶ月など）
  • 分析の切り口（カテゴリ別件数／よくある質問の抽出／ポジネガ判定）
TRIGGER きっかけ（いつ始まるか）
指定の集計日時（例：毎週月曜朝）または手動実行
OUTPUT 出力（何ができあがるか）
Googleドキュメント／スプレッドシートへの分析レポート

会議後の議事録を、指定の NotebookLM ノートへソースとして追加します。あとから決定事項や宿題をノート上で質問できます。

  • 対象の会議
  • 議事録の置き場
  • 格納先ノート
  • ファイル名（日付＋会議名）
TRIGGER きっかけ（いつ始まるか）

OUTPUT 出力（何ができあがるか）

S4 Studio
添付ファイルのGoogleドライブ自動格納

Google Workspace Studio

メールで届いた見積書や請求書などの添付ファイルを、指定したGoogleドライブのフォルダへ自動で整理・保存します。ダウンロードの手間を省き、ファイルの紛失や保存忘れを防ぎます。

PREP 事前準備（何を参照するか）
  • 対象とする添付ファイルの種類（見積・請求書／拡張子）
  • ファイル名の命名ルール（例：【受信日】+元ファイル名）
  • 同名ファイルが存在する場合の処理（上書き／別名保存／スキップ）
  • 保存先フォルダのURLと編集権限
TRIGGER きっかけ（いつ始まるか）
対象となる添付ファイル付きメールの受信
OUTPUT 出力（何ができあがるか）
指定の共有ドライブフォルダへのファイル格納（リネーム済）

S5 Studio
会議後のフォローアップメール下書き自動作成

Google Workspace Studio

クライアントとの打合せメモや議事録の文脈を読み取り、お礼・決定事項・次回アクションをまとめたメールの下書きを自動生成します。ゼロから文章を作る時間を短縮し、迅速なフォローを可能にします。

PREP 事前準備（何を参照するか）
  • 議事メモの置き場（Googleドキュメント等）
  • 宛先ルール（参加者全員／特定グループ）

G5 GAS
Googleフォームの自動受付制御（定員・期限）

Google Apps Script

回答数が定員に達した、または受付期限を過ぎたタイミングで、Googleフォームの受付を自動で停止します。手動で閉じ忘れる心配がなくなり、先着順の申し込みや期限内の申請を正確に運用できます。

PREP 事前準備（何を参照するか）
  • 対象のGoogleフォーム
  • 締め切り条件（定員数の上限／期限日時）
  • 受付停止後に画面表示する案内文
TRIGGER きっかけ（いつ始まるか）
回答数が定員に到達した瞬間、または指定日時が到来した瞬間
OUTPUT 出力（何ができあがるか）
フォームの受付停止処理および指定案内文の自動表示

詳細 G1 / G2

G1 GAS
複数スプレッドシートのデータ自動集計・統合

Google Apps Script

各部署や担当者が個別に入力している複数のスプレッドシートのデータを、毎日決まった時間に自動で1つのマスターシートに集約します。月末の手作業でのコピペや、集計ミスを完全に無くすことができます。

PREP 事前準備（何を参照するか）
  • 元シートの一覧とURL（列の項目名や順序が揃っているか）
  • 集約方式（全削除して上書き／末尾に新規行を追記）
  • 自身のGoogleアカウントの編集権限
TRIGGER きっかけ（いつ始まるか）
指定の実行タイミング（例：毎日深夜2時などのタイマー実行）
OUTPUT 出力（何ができあがるか）
集約先マスターシートへのデータ統合・更新
G2 GAS
Googleフォームと連動した社内申請・承認フローの自動化

Google Apps Script

経費精算や備品購入などの社内申請をGoogleフォームで受け付け、送信と同時に承認者の社内チャット（Google ChatやSlack）へ通知を飛ばします。確認から承認までのタイムラグをなくし、進捗状況もスプレッドシートで自動管理できます。

PREP 事前準備（何を参照するか）
  • 申請用Googleフォームと回答記録シート
  • 承認ルートと判定基準（承認者の指定）
  • ステータス管理列（未承認／承認／却下）
  • 却下（差し戻し）発生時の処理ルール
TRIGGER きっかけ（いつ始まるか）
Googleフォームからの申請送信（onFormSubmit）
OUTPUT 出力（何ができあがるか）
記録シートのステータス更新、およびGoogle Chat／メールへの判定通知

詳細 G3 / G4

G3 GAS
定例会議のアジェンダ（議事録）自動生成と事前共有

Google Apps Script

Googleカレンダーの定例予定をトリガーにして、会議の数日前に「前回の決定事項」や「今回のテンプレート」が記載された議事録（Googleドキュメント）を自動作成します。さらに参加者へリンクを自動通知し、事前の記入を促すことで会議時間を短縮します。

PREP 事前準備（何を参照するか）
  • 対象とするGoogleカレンダーの予定名
  • 議事録テンプレートURLおよび作成先フォルダURL
  • 命名ルール（例：【YYYYMMDD】会議名）と参加者共有ルール
TRIGGER きっかけ（いつ始まるか）
会議の〇日前（定時タイマー実行）
OUTPUT 出力（何ができあがるか）
作成先フォルダへの議事録ドキュメント生成＋参加者へのアクセス権限付与
G4 GAS
社内タスクや提出物の期限リマインド自動送信

Google Apps Script

スプレッドシート上の「タスク管理表」や「提出物リスト」をシステムが毎日チェックし、期日が迫っている、あるいは過ぎているのに「未完了」となっているメンバーにだけ、自動で催促のチャットやメールを送ります。管理者がわざわざ個別に催促する手間が省けます。

PREP 事前準備（何を参照するか）
  • タスク管理シート（期日列／担当者メールアドレス列／完了フラグ列）
  • リマインド送付条件（期日〇日前／期限超過）
TRIGGER きっかけ（いつ始まるか）
指定の実行タイミング（例：毎日朝9時）
OUTPUT 出力（何ができあがるか）
担当者への催促通知（メール または Google Chat Webhook）
